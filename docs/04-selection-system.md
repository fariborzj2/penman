# 04 - سیستم انتخاب (Selection System)

مدیریت دقیق Selection و Caret (نشانگر چشمک‌زن) یکی از پیچیده‌ترین بخش‌های هر Rich Text Editor است.

## وظایف سیستم Selection
1. **دریافت وضعیت (Get State):** خواندن Range فعلی (اینکه کاربر کجای متن را انتخاب کرده است).
2. **ذخیره و بازیابی (Save/Restore):** در زمان‌هایی که کاربر روی دکمه‌های Toolbar کلیک می‌کند، فوکوس از ادیتور برداشته می‌شود. این سیستم باید بتواند Selection را قبل از از دست رفتن فوکوس ذخیره کرده و مجدداً اعمال کند.
3. **گزارش‌دهی (Reporting):** اطلاع‌رسانی به UI برای روشن/خاموش کردن دکمه‌ها (مثلاً اگر کاربر متنی را انتخاب کرد که قبلاً Bold شده، دکمه Bold در Toolbar باید حالت فعال بگیرد).

## API مرورگرها
این سیستم مستقیماً با APIهای `window.getSelection()` و رابط `Range` جاوااسکریپت در تعامل است.

## چالش‌ها
- نرمال‌سازی تفاوت‌های جزئی در رفتار مرورگرهای مختلف.
- حفظ Range وقتی کاربر بین المان‌های مختلف جابجا می‌شود (مثلاً کلیک روی یک مودال).
- بدست آوردن نودهای متنی (Text Nodes) دقیقی که داخل Range انتخابی قرار دارند.
