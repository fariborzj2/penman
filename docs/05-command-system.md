# 05 - سیستم دستورات (Command System)

این سیستم مسئول اعمال تغییرات فرمت روی متن است.

## رویکرد (Approach)
در گذشته، ادیتورها به طور کامل بر `document.execCommand` متکی بودند. با توجه به اینکه این API در مسیر Deprecation (منسوخ شدن) قرار دارد، Penman Editor رویکردی ترکیبی (Hybrid) اتخاذ می‌کند:
1. **دستورات سفارشی (Custom Commands):** پیاده‌سازی منطق دستکاری DOM با جاوااسکریپت خالص برای اعمال فرمت‌ها (مثلاً پیچیدن متن انتخابی در تگ `<strong>` یا `<span>`).
2. **استفاده از execCommand (Fallback):** تنها در مواردی که هنوز جایگزین مناسبی وجود ندارد یا مرورگر رفتار استانداردی دارد.

## رجیستری دستورات (Command Registry)
سیستم دارای یک دایرکتوری از دستورات ثبت شده است. هر Command باید موارد زیر را تعریف کند:
- **نام:** شناسه دستور (مثل `bold`, `insertLink`).
- **اجرا (Execute):** تابعی که عملیات را انجام می‌دهد.
- **بررسی وضعیت (QueryState):** تابعی که بررسی می‌کند آیا این دستور روی Selection فعلی فعال است یا خیر (برای روشن کردن دکمه در Toolbar).

## مثال از روند کار
1. کاربر دکمه "Bold" را می‌زند.
2. رویداد کلیک دریافت می‌شود.
3. متد `editor.execCommand('bold')` فراخوانی می‌شود.
4. سیستم، Selection فعلی را می‌گیرد و تگ‌های `<b>` یا `<strong>` را روی نودهای متنی اعمال یا حذف می‌کند (Toggle).
