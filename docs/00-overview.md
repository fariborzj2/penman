# 00 - نمای کلی (Overview)

ادیتور **Penman** یک ویرایشگر متن غنی (Rich Text Editor) کاملاً مستقل، سبک و بدون وابستگی به هیچ فریم‌ورک جاوااسکریپتی (مانند React, Vue, Angular) است.

## هدف اصلی
ارائه یک ادیتور ساده، سریع و قابل اتکا که با کمترین دردسر در پروژه‌های وب سنتی یا مدرن قابل استفاده باشد و امکان شخصی‌سازی بالا را از طریق سیستم پلاگین خود فراهم کند.

## ویژگی‌های کلیدی
- استفاده مستقیم روی `<textarea>`
- بدون نیاز به وابستگی‌های خارجی (Zero Dependencies)
- ساختار ماژولار و مبتنی بر پلاگین
- استفاده از `contentEditable` با سیستم مدیریت یکپارچه محتوا

## مخاطبین
توسعه‌دهندگان وب که به دنبال یک ادیتور ساده برای فرم‌ها، سیستم‌های مدیریت محتوا (CMS)، یا وبلاگ‌ها هستند که بدون درگیری با سیستم‌های پیچیده build، مستقیماً قابل استفاده باشد.
