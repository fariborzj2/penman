# ListPlugin Usage

Automatically provides the `bullist`, `numlist`, `indentlist`, and `outdentlist` buttons to the editor UI.

## Buttons
- `bullist`: Create or toggle an unordered list.
- `numlist`: Create or toggle an ordered list.
- `indentlist`: Increase the nesting level of the current list item.
- `outdentlist`: Decrease the nesting level of the current list item.

## Keyboard Shortcuts
- `Tab`: Indent current list item.
- `Shift + Tab`: Outdent current list item.
