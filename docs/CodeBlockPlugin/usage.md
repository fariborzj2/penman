# CodeBlock Plugin Usage

### Creating a Code Block
1. Select the text you want to format as code.
2. Click the **Code Block** icon in the toolbar.
3. The text will be wrapped in a syntax-highlighted block with a dark theme.

### Editing Code
- **Automatic Highlighting**: Just type; the editor automatically detects the language and applies colors.
- **Indentation**:
  - Press **Tab** to indent by 2 spaces.
  - Press **Enter** to start a new line. The editor automatically maintains the current indentation level.

### Reverting to Text
- Click the **Code Block** icon while the cursor is inside a code block to convert it back to a standard paragraph.

### Breaking Out
- Use **Ctrl+Enter** (Windows) or **Cmd+Enter** (macOS) to immediately exit the code block and start a new paragraph below it.
