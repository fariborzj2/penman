# 07 - سیستم تاریخچه (History / Undo-Redo)

این سیستم برای لغو (Undo) و بازانجام (Redo) تغییرات استفاده می‌شود و جایگزین رفتار پیش‌فرض مرورگر است تا پایداری بیشتری ارائه دهد.

## ساختار پشته (Stack)
سیستم از دو پشته (آرایه) استفاده می‌کند:
- `undoStack`: لیست وضعیت‌های قبلی.
- `redoStack`: لیست وضعیت‌های لغو شده (برای بازگردانی).

## وضعیت (State) چیست؟
در هر لحظه که قرار است تغییری ثبت شود، یک "عکس فوری" (Snapshot) از ادیتور گرفته می‌شود که شامل موارد زیر است:
1. `html`: محتوای کامل داخل ادیتور (`innerHTML`).
2. `selection`: موقعیت Caret یا متن انتخاب شده، تا پس از Undo/Redo، نشانگر دقیقاً سر جای خودش برگردد.

## زمان‌بندی ثبت (Throttling / Debouncing)
اگر با هر بار فشردن کلید یک Snapshot ثبت شود، حافظه پر شده و Undo کردن یک حرف به یک حرف آزاردهنده می‌شود.
- سیستم با استفاده از Debounce/Throttle، تغییرات تایپی را گروه بندی می‌کند (مثلاً ثبت بعد از نیم ثانیه توقف در تایپ).
- تغییرات ساختاری (مثل زدن کلید Enter، کلیک روی دکمه Bold، Paste کردن) بلافاصله یک Snapshot جدید ثبت می‌کنند (معمولاً قبل و بعد از اعمال تغییر).

## جریان کاری Undo
وقتی `Ctrl+Z` فشرده می‌شود:
1. وضعیت فعلی از بالای `undoStack` برداشته شده و در `redoStack` قرار می‌گیرد.
2. وضعیت قبلی از `undoStack` خوانده می‌شود.
3. محتوای HTML ادیتور با این وضعیت جایگزین می‌شود.
4. Selection بازیابی می‌شود.
